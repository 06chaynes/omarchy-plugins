# GitHub Tracker & CI Alerts

A developer-first GitHub command center and CI/CD alert monitor for Omarchy Quattro.

## Features

1. **Pinned Repositories:** Keep your core projects front and center with live default branch CI status, open PR/issue counters, and quick actions.
2. **Action Alerts (CI/CD):** Real-time visibility into failing or pending GitHub Actions workflow runs on default branches and active PRs.
3. **Review Requests:** Track all pull requests waiting on your code review.
4. **My Pull Requests:** Monitor pull requests you authored with live check suite health and review approval states.

## Controls

| Action | Control |
|---|---|
| **Toggle Dashboard** | Left-click bar widget |
| **Cycle Bar Mode** (`BadgeCounts`, `AlertsOnly`, `IconOnly`) | Right-click bar widget |
| **Instant Refresh** | Middle-click bar widget or `R` in panel |
| **Switch Tabs** (Alerts, Reviews, My PRs, Pinned) | `1`, `2`, `3`, `4` or click tabs |
| **Search / Pin Repositories** | `/` in panel |
| **Pin / Unpin Repository** | Click pin icon or `P` |
| **Close Panel** | `Escape` or click outside |
