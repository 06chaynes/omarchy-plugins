# Changelog

## 1.1.0 - 2026-08-22

- Added Left and Right keyboard navigation between the Systems and ROMs panes
- Added contextual Up, Down, and Enter behavior for the active pane
- Added a visible accent border that identifies the active keyboard pane

## 1.0.0 - 2026-08-21

- Initial public release
- Console-sorted RetroArch playlist browser and direct launcher
- Native, Flatpak, Snap-style, and custom installation discovery
- Config-driven cores, assets, thumbnails, saves, and state directories
- Compatible per-game core overrides, favorites, and recent history
- Local artwork, system icons, folder shortcuts, and optional ROM Organizer integration
